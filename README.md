# TimTim - Your Dedicated Coding Companion

TimTim is an enthusiastic dinosaur with a passion for coding. Upon detecting a compatible coding environment, TimTim will appear in the corner of your browser to assist you.

## Features:
1. **Interactive Positioning**: Drag and drop TimTim anywhere on your screen for optimal convenience.
2. **Automated Coding**: Utilize TimTim’s built-in input field or have him type directly into your active coding area. By selecting "Let TimTim Type Here," he will generate valid Python, HTML, and JavaScript snippets.
3. **Customization**: Personalize your experience via the browser extension’s popup menu, which offers a wide array of configurable options.
4. **Engagement**: Click on TimTim to earn Dino Points. Additionally, you can interact with him through various activities: play a number-guessing game, engage in dialogue, or feed him to earn bonus Dino Points.

## Installation Instructions:
Step 1: Download the project .zip file and extract its contents.
Step 2: Navigate to `chrome://extensions` in your browser.
Step 3: Enable "Developer mode" using the toggle in the top-right corner.
Step 4: Click on "Load unpacked."
Step 5: Select the `TimTim-Chrome-Extension` folder from the extracted files.
Step 6: You are all set! Enjoy your coding companion.
